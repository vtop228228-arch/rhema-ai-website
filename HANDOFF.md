# Передача сайта Rhema AI — 14 сентября 2026

Рабочий сайт: https://rhema-ai-agency-amber.vercel.app

## Как Владу забрать проект

В существующей копии с чистым рабочим деревом: `git pull --ff-only origin main`.
Если есть свои незакоммиченные изменения, сначала сохраните их отдельным коммитом.
Затем `npm ci` и `npm run dev`. Для проверки production: `npm run build`, затем `npm start`.
Текущий стек: Next.js 16.2.6, React 19, TypeScript.

Скопируйте `.env.example` в `.env.local` и заполните необходимые значения.
Настоящие ключи находятся в настройках окружения проекта Vercel и не передаются через Git.
Без Anthropic не будет полноценного AI-диалога; без каналов доставки форма не должна сообщать об успешной отправке заявки.
