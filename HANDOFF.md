# Передача сайта Rhema AI — 14 сентября 2026

Рабочий сайт: https://rhema-ai-agency-amber.vercel.app

## Как Владу забрать проект

В существующей копии с чистым рабочим деревом: `git pull --ff-only origin main`.
Если есть свои незакоммиченные изменения, сначала сохраните их отдельным коммитом.
Затем `npm ci` и `npm run dev`. Для проверки production: `npm run build`, затем `npm start`.
Текущий стек: Next.js 16.2.6, React 19, TypeScript.

Скопируйте `.env.example` в `.env.local` и заполните необходимые значения.
Настоящие ключи находятся в настройках окружения проекта Vercel и не передаются через Git.
Без Anthropic не будет полноценного AI-диалога; без каналов доставки форма не должна сообщать об успешной отправке заявки.

## Что входит в версию

- Русская и английская версии сайта, услуги, контакты, юридические страницы и SEO.
- Кейсы Rhema OS, Besty, Маяк, Financefamily, ГорницаАналитик, D. Garabazhii, SigmaUp и Radar.
- Адаптивное оформление кейсов и реальные изображения продуктов. В Radar скрыты названия двух клиентских брендов.
- В блоке выбора задачи вместо непонятных фотографий — четыре схемы по три шага и ссылки с объяснением проекта.
- Согласие на аналитику, обработка ошибок формы и повторная отправка без потери ввода.

## Где редактировать

- `src/components/marketing/` — страницы, тексты, компоненты и оформление.
- `TaskPicker.tsx`, `TaskFlow.tsx`, `TaskPicker.module.css` в этой папке — выбор задачи и схемы.
- `src/lib/*cases.ts`, `src/lib/case-images.ts`, `src/lib/radar-case.ts` — данные кейсов и изображения.
- `public/cases/` — публичные материалы кейсов. Не добавляйте сюда оригиналы, которые должны оставаться скрытыми.
- `src/app/(ru)/` и `src/app/en/` — маршруты двух языков.
- `src/components/analytics/Analytics.tsx` и `src/lib/analytics-consent.ts` — аналитика и согласие.

## Публикация и оставшиеся настройки

Vercel: проект `rhema-ai-agency`, scope `tim-blassed`.
После входа в нужную команду: `vercel deploy --prod --yes --scope tim-blassed --project prj_MX5noyk18S5G8JOELiRXxbWD7fXo`.
Push в Git сам по себе не считается подтверждением публикации: проверяйте статус deployment и публичный адрес.

Свой домен подключается в Vercel; затем задаётся `NEXT_PUBLIC_SITE_URL` и выполняется новая сборка. Пока используется адрес выше.
В кабинете Метрики ещё нужно проверить создание целей из документа обновления. Доступ к кабинету в этой сессии отсутствовал.
Отзывы, подтверждённые результаты клиентов и сроки выполненных проектов можно добавить после согласования; вымышленных показателей нет.
